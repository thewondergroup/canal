# Canal — canalrestaurant.com

Static site for GitHub Pages. No build step needed to host it. `build.py` and `map_svg.py` generate the HTML pages.

## Updating the menus (Google Sheet)

1. Create a Google Sheet and import `data/menu.csv` (File › Import › Upload › Replace current sheet).
2. Keep the columns: `menu | section | item | description | price | tag`
   - `menu` is the tab the item shows under (`food`, `drinks`, or a new one like `brunch`).
   - `section` is the heading within the tab. Rows show in sheet order.
   - `tag` is optional: `v`, `ve`, `gf`.
3. File › Share › Publish to web › choose the sheet › **Comma-separated values (.csv)** › Publish. Copy the link.
4. Paste the link into `menuSheetCsv` in `js/config.js`.

From then on, edits to the sheet show on the site within a few minutes. If the sheet can't be reached, the site falls back to `data/menu.csv`.

## Hours, closures and the live strip

`js/config.js` holds opening hours and `closedDates` (e.g. `"2026-12-26"`). The "Open now / Sunset / Terrace" strip uses these, plus live weather from Open-Meteo (free, no key).

## Editing pages

Pages are generated by `build.py` (`python3 build.py`). Edit copy there and re-run, or edit the HTML directly for small changes.
